LOCAL GENERATIVE GRAPHICS

About Latent Field

Explore mathematical fields and pretrained image models, adjust their parameters, and save your results. Image processing runs locally; dataset search uses Wikimedia Commons. Start in the Lab with Folded Fractal.

Inception Dream

InceptionV3 feature visualization increases Mixed_6a and Mixed_6c activations through gradient ascent at several image scales. Quality and Reduced Compute use the same objective with different compute limits.

image → feature activations → normalized gradients → octave ascent

DigiFace Generator

A separately trained 48-dimensional beta-VAE decoder runs locally through ONNX Runtime Web. Feature controls expose the selected latent axis so users can see when eyes, nose, mouth, expression, and age-like appearance are entangled rather than pretending every slider is perfectly semantic.

z → ONNX decoder → 112 × 112 RGB → optional color transform

Chromatic Flow

A WebGL fragment shader evaluates a warped mathematical signal for every pixel.

color = field(transform(uv, time, parameters))

Folded Fractal

A recursive coordinate field repeatedly applies folding, rotation, inversion, translation, and symmetry. Ghost Effect adds offset contours only when it is enabled.

coordinates → fold → rotate → invert → translate → repeat

Fractal Explorer

Mandelbrot, Julia, Burning Ship, and Tricorn iterations visualize escape time, orbit traps, zoom, and sensitivity to complex constants. Click or drag moves through the selected equation. Right-click or touch-hold starts a small optional motion while your direct moves stay as the base view.

zₙ₊₁ = f(zₙ) + c

Quick Local Model

Model Studio reduces user-selected RGB images to a local color basis. Training happens in a Web Worker and the model can be exported as JSON.

local images → covariance → color basis

MODULATION & MOTION

Every numeric slider can connect to an internal LFO with selectable waveforms (sine, triangle, saw, square, noise), rate, and depth. Audio reactivity lets any parameter dance to whole-music bass or focused kick transients.

base view → LFO oscillator → audio reactivity

MODULATION MATRIX

Any numeric slider can combine an LFO with either a bass-weighted whole-music envelope or a focused kick transient. Each audio route has a bipolar depth control, while the live markers and four-second history graph show the final effective value.

value(t) = base + LFO(t) × depth + audio(t) × depth
